# User Guide

## 1. Transforming Tab Audio in One Click

1. Open any website playing audio in Google Chrome (YouTube, Spotify Web, SoundCloud, Apple Music Web, podcasts, news interviews, or HTML5 video).
2. Click the **Vintage Radio** dial icon in your Chrome toolbar.
3. Click **Enable Radio**.
   - Audio from the active tab immediately routes through the receiver model in real time.
   - The toolbar icon displays a muted green **`ON`** badge so you always know which tab is active even after closing the popup.
4. To restore completely unmodified browser playback at any time, click **Stop Radio** (or simply close the tab).

---

## 2. Comparing Original vs. Processed Fairly (`B` Key)

Human ears naturally prefer whichever signal is `1–2 dB` louder. Every Vintage Radio profile is calibrated so **Processed** and **Original** match broadband loudness within `±1.5 dB`.

- Click **Original** / **Processed** in the popup (or press **`B`** on your keyboard while the popup is open) to crossfade smoothly (`25 ms`) between unmodified audio and the active radio receiver.
- While bypassed, the toolbar badge displays **`BYP`**.

## 4. Primary & Calibration Controls

- **Character Intensity (`0% – 100%`, default `75%`):** Scales filter bandwidth, cabinet/cone resonances, harmonic saturation drive, and broadcast compression together. Lower toward `35–50%` for subtle coloration; push toward `90–100%` for pronounced vintage character.
- **Receiver Static (`Off` – `100%`) & `Auto-duck`:**
  - Drag to `0%` (`Off`) for completely silent, zero-CPU noise disable.
  - Keep **Auto-duck** enabled (default) so radio static gently fades down whenever you pause your video or podcast.
- **Calibration (`+` Drawer):**
  - **Channel Width (`Mono` – `100%`):** Override any preset's stereo width from true monaural (`0%`) up to full original stereo (`100%`).
  - **Skywave Drift (`Off` – `100%`):** Adds slow ionospheric selective-fading movement without seasick pitch warble.
  - **Reset Preset:** Restores the selected profile's researched default calibration.

## 5. Using the Signal Workbench (`Workbench ↗`)

Click **Workbench ↗** in the bottom-right corner of the popup to open the full-page **Signal Workbench**:

- Click **Play Reference Audio** to audition presets immediately against four built-in reference signals (_Warm Electric Piano_, _Spoken Cadence + Pause_, _65 Hz Sub-Bass + Pulse_, and _Calibrated Pink Noise_)—ideal for testing even when no external streaming tab is open.
- Inspect the live `20 Hz – 20 kHz` transfer curve and exact electroacoustic parameters for each receiver profile.
